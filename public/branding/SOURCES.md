# Shelves branding

- `shelves.svg`: user-supplied `C:\Users\User\Downloads\download.svg`, copied unchanged.
- `shelves-loading.svg`: derived from the supplied book/bookmark paths, with the wordmark removed and a looping CSS animation. Original artwork colors are preserved. Both assets honor reduced-motion preferences.
- `icon.svg`: static square adaptation of the supplied stacked-book paths on the Shelves paper color. `icon-32.png`, `icon-180.png`, `icon-192.png` and `icon-512.png` are rasterized from that SVG for browser-tab, touch and app-manifest support.
