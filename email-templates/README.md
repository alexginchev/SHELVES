# Shelves password reset email for EmailJS

**Subject:** `A fresh page for your Shelves account`

In the EmailJS template editor, set **To Email** to `{{to_email}}` and paste the contents of `password-reset.html` into the HTML content editor. Send these template parameters from the Shelves server:

| Parameter | Value |
| --- | --- |
| `to_email` | The account email address |
| `action_url` | The one-use reset URL generated by Shelves |
| `logo_url` | The public HTTPS URL of `/branding/shelves-email.png` on your deployed Shelves site |

The logo PNG is derived from the user-supplied Shelves wordmark, without animation, for email clients. `shelves-email.svg` is the editable source. The URL for `logo_url` must be publicly reachable; a local `127.0.0.1` URL will not display in a recipient's inbox.

Shelves currently sends account email through Resend in `server/account-links.ts`. Pasting this template into EmailJS creates the template but does not switch the app's mail provider.
